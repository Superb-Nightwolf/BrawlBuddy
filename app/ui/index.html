Why are these manual?

The official API provides public account statistics and unlocked brawlers, but it does not provide your private Coins, Power Points, Gems, Credits, or Bling balance.

  • Balances are stored in local SQLite.
  • Each player tag has its own wallet.
  • No wallet value is sent to Supercell.
  • Recommendation math will use these values later.
