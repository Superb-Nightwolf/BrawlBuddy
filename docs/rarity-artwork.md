# Rarity skull artwork

The rarity badges use the skull from Supercell's official Brawl Stars Fan Kit
**BS_Symbol** logo asset (asset ID `106647`), checked on 2026-10-04.

- Collection: https://fankit.supercell.com/d/YvtsWV4pUQVm/logo
- Source file: https://media.ffycdn.net/eu/supercell/iDDkpmgeytwamnPsg6xz.png?width=2400
- Original: `app/ui/assets/brawl-stars-symbol-official.png` (1502 × 852)
- Badge asset: `app/ui/assets/rarity-skull.svg`

The original PNG is preserved unchanged. The SVG embeds that artwork and masks
the gold skull into the existing dark badge ink, excluding the surrounding ring
and preserving the original outline, tilt, eyes, eyebrows, and nose. It needs no
external requests at runtime. Rarity colors and the separate tier labels remain
defined by the roster dropdown styles.
